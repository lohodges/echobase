## To create new branch
### No work should occur on the main branch. Be sure that you are on the correct branch before changing anything
```
git checkout -b <your-initials>-<preferred name of your branch>
```

## To switch branches
```
git switch <branch name>
```

## To pull updates from main branch to your local machine
```
git pull
```

## To check your remote origin
### It should be origin  git@github.com-lohodges:lohodges/echobase.git (fetch)
### origin  git@github.com-lohodges:lohodges/echobase.git (push)
```
git remote -v
```
